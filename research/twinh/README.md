## 확인한 구성

브라우저에서 검은 배경의 전체 화면 히어로, 큰 Pretendard 제목, 붉은 주요 버튼, 흑백 섹션 전환, 가로로 이동하는 타이포그래피, 6개 서비스 아코디언, 제작 단계와 큰 하단 CTA를 확인했다. 서비스 항목 클릭 시 내용이 펼쳐지는 동작도 확인했다.

REA는 공개 스크립트 14개를 오류 없이 파싱했다. jQuery 1.12.4, jQuery Migrate와 Owl Carousel의 파일 URL을 관찰했으며 페이지 내부 스크립트와 main.js/sub.js 등을 함께 분석했다. 정적 분석 범위는 partial로 보고되어 사이트 전체 기능이나 서버 구현을 확인한 것으로 해석하지 않는다. 수집 시작 전 네트워크 동작과 서버 내부 구현은 관찰 범위에 없다.

## 홈페이지에 적용한 방향

- 전체 화면 히어로와 큰 한국어 제목, 붉은 CTA, 흑백 대비를 유지했다.
- 회사 서비스 소개를 창작자의 기획·바이블·쇼트·에셋·스토리보드·패키지 흐름으로 바꿨다.
- 그래픽, 브랜드, 문구, HTML/CSS/JavaScript는 새로 작성했다.
- 기본 브라우저 기능과 자체 JavaScript로 아코디언, 모바일 메뉴와 진입 화면을 구현했다.
- 초기 작업실은 브라우저에 기획을 보관하며, 아직 구현되지 않은 AI 제작 기능을 사용 가능하다고 표시하지 않는다.

- 기획 파일 왕복, 입력 오류, 손상·중복 보관함 보호 등 Node 테스트 5개 통과.
