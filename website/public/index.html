GOOD TO KNOW

시작하기 전에.

작업실에 대해 궁금한 것들.

지금 어떤 기능을 사용할 수 있나요?+

짧은 아이디어나 준비한 기획을 넣고 GPT와 대화하며 기획을 확정합니다. 캐릭터·장소·장면 이미지를 만들고 수정·선택한 다음, 확정된 에셋과 기획서·스토리보드·영상 프롬프트를 ZIP으로 다운로드할 수 있습니다.

완성된 영상도 만들어 주나요?+

AI Asset Studio는 영상 제작에 앞서 기획과 시각 자료를 준비하는 프리프로덕션 작업실입니다. 완성 영상의 생성과 렌더링은 외부 영상 도구에서 진행하는 방향으로 설계되어 있습니다.

작업 내용은 어디에 저장되나요?+

프로젝트와 대화, 확정된 기획과 이미지 버전은 로그인한 계정의 서버 저장소에 보관됩니다. 이전 브라우저 기획은 작업실의 가져오기로 옮길 수 있습니다. 입력은 JSON으로 백업하고, 확정 에셋은 ZIP으로 보관하세요.

시작하면 API 비용이 발생하나요?+

현재 기획 보관함은 외부 AI API를 호출하지 않으므로 API 사용료가 발생하지 않습니다. AI 기능을 연결할 때는 실행 전 예상 비용을 표시하고 월·프로젝트 예산 안에서 승인된 작업만 실행하도록 설계합니다.
